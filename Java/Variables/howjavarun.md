☕ How Java Code Runs — 
Write: Java code .java file mein likhte hain, jaise Main.java.
Compile: Java Compiler (javac) code ko check karke .class file banata hai.
Bytecode: .class file mein bytecode hota hai.
JVM: JVM bytecode ko execute karke program ko run karti hai.
Platform Independent: Java ka bytecode different operating systems (Windows, Mac, Linux) par run ho sakta hai, agar wahan JVM available ho.

👉 Isliye same Java code ko different PC/Mac par dobara likhne ki zarurat nahi hoti. .class file/bytecode ko use karke program run kiya ja sakta hai.

⭐ Easy Flow:

.java → Compiler → .class (Bytecode) → JVM → Output
